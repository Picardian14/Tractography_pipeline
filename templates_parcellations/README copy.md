# Template parcellations

The 52 atlas directories use the IDs in `atlases.tsv`. Each has a `volume/` directory. Where a published surface representation is available, `surface/` identifies the mesh space. FreeSurfer annotations come as left and right pairs. CIFTI files use fsLR32k cortical grayordinates, with subcortical voxels included in the combined Schaefer–Tian files.

For `tck2connectome`, use a 3D integer label volume in the same physical space as the tractogram. Remap sparse atlas IDs to a contiguous sequence if matrix rows must correspond directly to the present parcels. DiFuMo, MSDL, and Smith are 4D component maps and require a separate assignment method to make discrete connectome nodes.

## Lookup tables

lut_index.tsv lists the representation, source files and lookup path for each atlas. Each atlas has a lut/nodes.tsv. Deterministic tables give the matrix node, source ID and region name. In Yeo a pair of source IDs denotes left and right hemisphere inputs merged into one network. Component tables give the component number and zero-based fourth-axis index.

For deterministic atlases, LUT_<atlas>.txt and LUT_<atlas>_OUTPUT.txt are the MRtrix input and output. Each pair was tested with labelconvert on an image containing every expected source ID. This tests lookup independently of anatomical registration. The existing jobs read LUTs and annotations from one directory, while this collection keeps them in separate subdirectories.

Schaefer input tables come from CBIG's [project_to_individual](https://github.com/ThomasYeoLab/CBIG/tree/master/stable_projects/brain_parcellation/Schaefer2018_LocalGlobal/Parcellations/project_to_individual) folder. The published Freeview LUT gives the output order. For Yan the annotation provides hemisphere-specific input IDs and the Freeview LUT provides output order. Glasser uses the downloaded annotation names with the _ROI suffix. MRtrix also distributes hcpmmp1_original.txt and hcpmmp1_ordered.txt; its output includes subcortical nodes beyond the 360 cortical parcels. [MRtrix tables](https://github.com/MRtrix3/mrtrix3/tree/master/share/mrtrix3/labelconvert)

For native Destrieux, use destrieux/lut/native_aparc_a2009s/ with the standard subject aparc.a2009s+aseg.mgz. Source IDs follow the [FreeSurfer 6 color table](https://github.com/freesurfer/freesurfer/blob/v6.0.0/distribution/FreeSurferColorLUT.txt). Its 148 cortical parcels retain their corresponding IDs in the lateralized Nilearn ordering. Slots 42 and 117 are reserved and medial walls map to background. The parent pair accepts the lateralized Nilearn volume.

AAL uses the 166-region AAL3v2 volume. Glasser uses a surface-derived subject volume. Its hemisphere-split template NIfTI already has a matching TSV. The combined Schaefer–Tian entries describe the published final numbering after merging cortex and subcortex. BASC and Smith retain numbered parcel and component identities. The 4D atlases have component lookup tables. To record subject coverage, join voxel counts to the atlas IDs in nodes.tsv.
